# pain_exam

台灣疼痛醫學會疼痛專科醫師考古題互動練習網站（繁體中文）。

## 使用方式

這是靜態網頁專案，不需要安裝套件或資料庫。直接開啟 `index.html` 即可練習。若啟用 GitHub Pages，也可透過瀏覽器直接連線使用。

- **第一輪：整年度模擬考**。回答整份試卷後交卷，才公布官方答案與解析。
- **第二輪：逐題即時複習**。完成的年度才開放逐題作答，答題後立即查看結果。
- **錯題簿**。自動標記答錯的題目，持續保留至手動標記為已熟悉。
- **進度備份**。網站使用瀏覽器本機儲存，請定期匯出 JSON 備份，換瀏覽器或設備時再匯入。

## 題庫範圍

- 民國 **106～115 年**：連續十年，共 **499 題**（107 年取得的原始檔只有 49 題）。
- 民國 **105 年**：額外練習 **50 題**。
- 合計 **549 題**。

題目依學會歷年考卷整理。已匯入官方答案，**不代表所有題目已完成獨立醫學驗證**；部分舊題可能有印刷錯誤、爭議或與較新指引不符，請留意網站標記與來源。

## 專案結構

- `index.html`：完整互動網站與內建題庫，為目前主要版本。
- `README.md`：專案使用說明。
- `.gitignore`：排除暫存檔。

## 開發與版本管理

使用 GitHub 的 Commit 歷史追蹤每次變更；建議每次更新包含清楚的 commit 訊息，例如：

- `fix: 修正 106 年第 2 題解答註記`
- `feat: 新增年度答題統計`
- `docs: 補充醫學文獻來源`

## GitHub Pages

進入 repo 的 **Settings → Pages**，在 **Build and deployment** 選 **Deploy from a branch**，來源選 `main` 與 `/(root)`。這會以 `index.html` 作為首頁。

> 注意：目前 repo 為 **Public**。GitHub 上的題庫與程式可由其他人瀏覽；作答紀錄並不會自動同步到 GitHub。

## 版權與醫學資訊

歷屆試題的原始內容及引用參考著作權屬各自權利人。此專案作為個人考前學習工具。醫學內容僅供學習與核對，臨床決策應參考最新正式指引和個別病人情況。
