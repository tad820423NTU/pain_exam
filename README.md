# pain_exam

台灣疼痛醫學會疼痛專科醫師考古題互動練習網站（繁體中文）。

製作：**Chia-Hao Ho × ChatGPT (OpenAI)**。題庫與網站版本由此 GitHub repository 維護。

## 立刻開始

- **線上**：在 GitHub 的 **Settings → Pages** 設定 `Deploy from a branch`，選擇 `main` 和 `/(root)`。啟用後可由 GitHub Pages 開啟網站。
- **離線**：請先 **Code → Download ZIP**，解壓縮後開啟 `index.html`。要保留 `data/` 資料夾與首頁的相對位置；只下載單獨的 `index.html` 無法載入題庫。
- **更新題庫**：由 GitHub 修改各年度 `data/年份.js`，網站不提供 PDF 匯入功能。官網歷屆試題入口只在首頁保留一處。

## 練習模式

1. **第一輪：整年度模擬考**。依 **115 → 114 → … → 106**（105 年為加練）的順序選擇年度。作答時**每次選擇答案都會自動暫存**；可按「暫存並離開」回到首頁，下次點選同年度「繼續作答」從上次題號與作答紀錄繼續。必須整份作答完、**正式交卷後才會顯示答案與解析**。
2. **第二輪：逐題即時複習**。僅完成過第一輪的年度才解鎖。每題選項確認後，立即公布正誤及詳解，再進下一題。
3. **錯題簿**。答錯自動加入，直到使用者手動標記為已熟悉。
4. **資料備份**。作答紀錄與未交卷的年度暫存都保存在此瀏覽器的 localStorage；網站也會將**未交卷暫存納入 JSON 備份**。可匯出後在其他裝置匯入並接續練習，但不會因 GitHub Commit 而自動跨裝置同步。注意：清除網站資料、使用無痕模式或更換瀏覽器可能造成暫存遺失。

### 官方答案與醫學爭議

- **只用學會公布的答案計分**，包含第一輪、第二輪、錯題簿與成績統計。
- 若原題、答案鍵與較新文獻不一致，保留學會答案。其他可能正解只在**詳解中的「醫學補充」**討論，不改計分。
- 第一次整份交卷前不顯示答案或任何特定題目的爭議內容；完成第一輪後，第二輪每題確認作答才揭曉。

### 暫存與正式交卷

- 「暫存」**不等於交卷**：不公布答案、不計分、不標記錯題、不解鎖逐題複習。
- 暫存依年度分開保存，不會因為開始別的年度就覆蓋原來的紀錄。
- 「重新開始」會要求確認，只有確認後才捨棄該年度未交卷的暫存。
- 全部作答完成、點選「全部交卷／看詳解」後，才寫入成績與完成狀態，並移除該年度的暫存。

## 專案結構

```text
pain_exam/
├── index.html          # 網站 UI 與功能邏輯
├── data/
│   ├── 106.js          # 106 年 50 題
│   ├── ...             # 107～115 年題庫，各自獨立
│   └── 105.js          # 額外練習 50 題
├── README.md
└── .gitignore
```

各年度 `data/年份.js` 會在頁面載入時把考題附加到 `window.PAIN_EXAM_SEEDS`，首頁再使用 `const SEEDS=window.PAIN_EXAM_SEEDS||[]`。這樣日後更新某個年度的題目或詳解，可以單獨修改對應檔案，再 Commit，不需要更新超過 1 MB 的單體 HTML。

### 日後如何修改

- 修改介面或作答流程：編輯 `index.html`。
- 修正題目、官方答案或詳解：編輯 `data/<年度>.js`。
- 可直接在 GitHub 編輯檔案、輸入 Commit message；也能使用本機 Git 或請 ChatGPT 連線後協助建立 Commit。

建議用簡潔的 Commit message：

- `fix: 修正 114 年第 6 題爭議註記`
- `feat: 新增跨年度錯題統計`
- `docs: 補充文獻查證說明`

## GitHub Pages

進入 **Settings → Pages**，在 **Build and deployment** 選擇 **Deploy from a branch**，設定 `main` 和 `/(root)`，按 **Save**。GitHub Pages 啟用後通常會提供 `https://tad820423ntu.github.io/pain_exam/` 作為網站網址，請以 Pages 設定頁顯示的正式網址為準。
